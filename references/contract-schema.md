## Case switching (runtime)

- Proxy injects `x-mock-case` from session `cases.active` / `cases.default` (or scenario).
- Handler may also read `?__mockCase=` / `?mockCase=`.
- **`when` on contract cases is documentation / future matching.** Runtime case selection today is **header/query driven**, not per-request `when` evaluation on the mock router.
- **Proxy rules** may include `when.query` / `when.header` for rule matching (host+path+method+when).

## Coverage gaps

Gap types are a closed set defined in [`lib/gap-taxonomy.js`](../lib/gap-taxonomy.js), grouped by failure layer (framework-agnostic):

| gap | layer | meaning | statically resolvable? | disposition |
|-----|-------|---------|------------------------|-------------|
| `no_export_symbol` | discover | URL found but no export bound | partial | contract-only |
| `no_callsite` | bind | export never called (dead export) | no | contract-only |
| `bind_ambiguous` | bind | export key / alias unresolved | yes | strengthen binding |
| `TRACE_EMPTY` | trace | callsite exists but response shape empty | partial | extend trace or capture |
| `no_property_access` | trace | export found, no field access | partial | extend trace or capture |
| `props_shallow_only` | trace | only shallow props read | yes | cross-file props-drill |
| `dynamic_key` | trace | `obj[key]` / runtime path | no | capture / OpenAPI |

`skippedEmpty`: empty shape + `no_export_symbol` **or** `no_callsite` → contract written, **no handler**, not in `proxy-rules.json`. `TRACE_EMPTY` keeps a handler (callsite exists → capture-merge can fill it). Dead exports are listed in `coverage-summary.json#deadExports` (stubId + exportHint) for human triage; the tool never modifies the business repo.

## Fidelity

Each contract carries a `fidelity` field (L0..L3) derived from `response.source` + `response.shape`:

| level | label | when |
|-------|-------|------|
| `L0` | empty envelope | no shape, no capture |
| `L1` | schema/usage/doc shape + placeholder | non-empty shape, source `usage`/`empty`/`openapi`/`wiki` |
| `L2` | captured example | `response.source` contains `capture` |
| `L3` | scenario / stateful | contract has `virtualService.protocol` (or reserved) |

Upgrade path: L0→L1 via `import-openapi` / `import-doc` or better usage; L1→L2 via `session` + `capture-merge`（wiki 不覆盖已有 capture）。The init report (`coverage-summary.json`) exposes `fidelity`, `gapsByType`, `emptyStubsByGap`, and `deadExports` (empty + `no_callsite`).
